Add `warp.geometry.oriented_bounding_box()`, which fits an approximate oriented bounding box to a point set on the
device by scoring candidate orientations from a Super-Fibonacci spiral over SO(3) (plus the axis-aligned and PCA
frames), refining several distinct best candidates with a coarse-to-fine local search followed by spins about the box
axes, and keeping the box that minimizes its volume, surface area or mean width. Very large point clouds can optionally
be searched over a strided subsample (`max_search_points`) while the returned box is always measured exactly over every
point, and the whole fit can be captured in a CUDA graph.

Add `warp.geometry.oriented_bounding_boxes()`, which fits oriented bounding boxes to many point sets stored back to back
in one array in a single batched pass, avoiding the per-call launch overhead of fitting small point sets one at a time.
