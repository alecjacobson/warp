Add the `warp.geometry` module with `warp.geometry.triangle_mesh_topology_statistics()`, which
summarizes the combinatorial topology of a triangle mesh -- edge incidence and orientation,
vertex manifoldness, and combinatorially degenerate triangles -- from a `(num_triangles, 3)` `int32`
index array, without vertex positions. It returns a `warp.geometry.TriangleMeshTopologyStatistics`
with scalar counts and derived predicates such as `is_manifold`, `is_closed_manifold`, and
`is_oriented`. Statistics are gathered on the Warp device (CPU or CUDA) with a sort-free
count/scan/scatter pipeline that builds a vertex-to-incident-corner CSR, so no global key sort is
needed and only a single small counter array is read back to the host.
