Add an initial `wp.summand` / `wp.indexed_sum` API for assembling the value, gradient, and sparse Hessian of a summed
local energy. Manual derivatives are written with `@wp.summand_grad` / `@wp.summand_hessian` using an argument-indexed
dict convention; a bound value exposes `value.value`, `value.gradient[x]`, `value.vjp(x, seed)`, and
`value.hessian[x, x]` (a `warp.sparse.BsrMatrix`). Summands may take one non-differentiable per-element scalar
parameter (e.g. a spring rest length) via a second index array, and values compose (`a + b`, `scale * a`) into a
weighted sum. Derivatives use the hand-written rules by default, or `wp.indexed_sum(..., backend="fd")` to obtain them
by finite-differencing the energy (no derivative rules required). This first version covers a single
`wp.array(dtype=wp.vec3)` variable over 1-, 2-, or 3-node stencils; see `design/sparse-hessians.md` and the
`optim/example_spring_hessian.py`, `optim/example_catenary.py`, and `optim/example_catenary_fd.py` examples.
