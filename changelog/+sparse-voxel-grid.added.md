Add :func:`warp.geometry.sparse_voxel_grid`, a pure-Warp analogue of libigl's ``igl::sparse_voxel_grid``. Starting from a seed cell, it flood-fills the connected set of grid cells that straddle the zero level set of a ``@wp.func`` implicit function -- entirely on the GPU and using only sparse ``O(M)`` storage (a concurrent ``atomic_cas`` hash set plus multi-step block work with global spill queues), never a dense ``n^3`` grid -- and returns the occupied voxels' unique corner positions, sampled field values, and per-voxel corner indices. See ``warp/examples/benchmarks/benchmark_sparse_voxel_grid.py``.
