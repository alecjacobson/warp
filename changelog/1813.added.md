Add `wp.JetSpace()` and `wp.JetSpace2()`, forward-mode jet types that carry a value together with its derivatives.
Evaluating an ordinary `@wp.func` over them yields its gradient (`wp.JetSpace()`) or its gradient and dense Hessian
(`wp.JetSpace2()`) with no hand-written derivatives, using ordinary Warp syntax such as `a * b`, `wp.sin(a)`,
`wp.length(d)` and `wp.determinant(m)`. The number of derivative directions is fixed when the types are created, so
these suit local derivatives of a fixed number of variables -- one spring, triangle, or tetrahedron -- rather than
differentiation with respect to an unbounded number of variables, which remains reverse mode's job. See
`warp/examples/optim/example_implicit_projection.py` and `design/forward-mode-jets.md`.
